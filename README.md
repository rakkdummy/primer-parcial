En resumen, la triada CIA sirve como modelo fundamental para diseñar políticas, controles y estrategias de ciberseguridad que equilibren estos tres pilares y minimicen los riesgos de pérdida, alteración o indisponibilidad de los datos

Autenticación offline (SDA / DDA / CDA)

Se verifica que la tarjeta es genuina y que sus datos no han sido alterados

→ Integridad + autenticidad.

Verificación del titular (CVM)

PIN (cifrado), firma o sin verificación (montos bajos)

→ Confidencialidad del PIN.

Gestión de riesgos

Terminal y tarjeta deciden si la transacción puede ser offline o debe ir online

→ Disponibilidad.

Generación del criptograma (ARQC / TC / AAC)

La tarjeta crea un código criptográfico único (MAC) con una clave secreta y un contador

→ Integridad (protege todos los datos de la transacción) + Confidencialidad (la clave nunca sale del chip).

Autorización online (si es necesario)

El emisor verifica el ARQC y responde con un ARPC

→ Autenticación mutua (Integridad).

Finalización

Se genera el certificado final de la transacción y, si aplica, se ejecutan scripts seguros del emisor.
